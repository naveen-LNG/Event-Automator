# Quarantined Merge references

Files in this folder are deliberately NOT loaded as style references.
`art_reference._images_in()` lists only files whose name ends in an image
extension directly inside `images/Merge/`, so a subdirectory is skipped — that
is what keeps these out, not naming.

## merge2606_scene3_toy_cars_HAS_CALLOUT_NUMBERS.png

The Toy Car World concept art from Merge2606 page 8. Good art, unusable as a
reference: it carries circled callout numbers 1–8 stamped over the buildings as
a requirement-document annotation.

Attaching a numbered image as a style anchor is how an earlier Sort render
learned to draw circled callout markers and a numbered key into finished
artwork. Prose banning text did not undo it; removing the numbered reference
did. Do not move this file up a level.

If Toy Car World is ever needed as an anchor, take a clean render of it — not
this page.
